# Keyboard shortcuts

`Mod` means **Cmd** on macOS and **Ctrl** on Windows and Linux.

Shortcuts are taken from the editor source (`editor/components/tiptap-ui/*`). Shortcuts in the
"Blocks and menus" section are registered by their toolbar or menu control, so they work while that control is
available in the current editor view.

## Text formatting

| Action | Shortcut |
|---|---|
| Bold | `Mod` + `B` |
| Italic | `Mod` + `I` |
| Underline | `Mod` + `U` |
| Strikethrough | `Mod` + `Shift` + `S` |
| Inline code | `Mod` + `E` |
| Superscript | `Mod` + `.` |
| Subscript | `Mod` + `,` |
| Highlight color | `Mod` + `Shift` + `H` |
| Text color | `Mod` + `Shift` + `T` |

## Paragraphs and headings

| Action | Shortcut |
|---|---|
| Normal text | `Mod` + `Alt` + `0` |
| Heading 1 – 6 | `Ctrl` + `Alt` + `1` … `6` |
| Align left | `Mod` + `Shift` + `L` |
| Align center | `Mod` + `Shift` + `E` |
| Align right | `Mod` + `Shift` + `R` |
| Justify | `Mod` + `Shift` + `J` |

## Lists, quotes and code

| Action | Shortcut |
|---|---|
| Bullet list | `Mod` + `Shift` + `8` |
| Numbered list | `Mod` + `Shift` + `7` |
| Task list | `Mod` + `Shift` + `9` |
| Blockquote | `Mod` + `Shift` + `B` |
| Code block | `Mod` + `Alt` + `C` |

## Blocks and menus

| Action | Shortcut |
|---|---|
| Open slash command menu | `Mod` + `/` |
| Insert mention | `Mod` + `Shift` + `2` |
| Insert emoji | `Mod` + `Shift` + `E` (same keys as Align center) |
| Upload image | `Mod` + `Shift` + `I` |
| Download image | `Mod` + `Shift` + `D` |
| Duplicate block | `Mod` + `D` |
| Delete selected block | `Backspace` |
| Move block up | `Mod` + `Shift` + `↑` |
| Move block down | `Mod` + `Shift` + `↓` |
| Copy block | `Mod` + `C` |
| Copy link to block | `Mod` + `Ctrl` + `L` |
| Ask AI | `Mod` + `J` |
| Close a menu or popover | `Esc` |

## History

| Action | Shortcut |
|---|---|
| Undo | `Mod` + `Z` |
| Redo | `Mod` + `Shift` + `Z` |

## Reflection sidebar

| Action | Shortcut |
|---|---|
| Save reflection | `Cmd` + `Enter` |
| Cancel editing | `Esc` |

## Disabled browser shortcuts

The app blocks these so a stray key press can't reload the window or open dev tools:
`Mod` + `R`, `Mod` + `Shift` + `R`, `Mod` + `Shift` + `I` and `F12`.
